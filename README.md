# GaussVIO

**Visual-Inertial Odometry Driven Online 3D Gaussian Mapping**

GaussVIO is a research project for **online 3D Gaussian Splatting mapping driven by visual-inertial odometry**. It combines VIO-based camera tracking with incremental 3D Gaussian scene reconstruction to build a dense and renderable 3D representation while the camera is moving.

The project focuses on a decoupled tracking-and-mapping pipeline, where visual-inertial odometry provides stable camera poses and the 3D Gaussian backend incrementally maintains the scene representation.

## Main Directions

- Visual-inertial camera tracking
- Online incremental 3D Gaussian mapping
- Dense and renderable scene reconstruction
- SLAM / visual navigation research
